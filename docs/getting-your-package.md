# Getting your package

Everything this tool shows you comes from the data package Discord can send you. Here is how to get one.

## Requesting it

1. Open Discord and go to User Settings
2. Open the Privacy and Safety page
3. Scroll to the bottom and press Request Data
4. Wait for the email from Discord, it can take days to a couple of weeks

## Opening it

When the email arrives, download the attachment and unzip it. Inside you will find a file called `package.zip`. That is the one this tool wants.

You can open it two ways:

- Start the app, press Select Package and pick the `package.zip`
- Or just drag the `package.zip` onto the app window

The app loads it in the background, so a huge package just shows a progress bar instead of freezing. Loading and searching never touch the network.

## What is inside

- Messages: every message you have ever sent, with attachments
- Servers: every server you have joined, when and how you joined, invites you used
- DMs: every DM and group DM channel you have talked in
- Activity: data Discord keeps about your account, used to figure out whether old messages survived
